# 🧠 LifeRelier AI Assistant Knowledge Base

Version: 1.0

Project: LifeRelier Healthcare Platform

---

# Purpose

This document defines the healthcare knowledge domains supported by the LifeRelier AI Assistant.

The assistant provides educational healthcare guidance within these domains.

---

# 1. Symptoms

Supported Symptoms:

- Headache
- Fever
- Cough
- Cold
- Fatigue
- Dizziness
- Vomiting
- Nausea
- Chest Pain
- Shortness of Breath
- Back Pain
- Stomach Pain
- Joint Pain
- Body Ache
- Sore Throat
- Diarrhea
- Constipation

Capabilities:

- Follow-up questioning
- Possible causes
- Self-care guidance
- Escalation recommendation
- Emergency detection

---

# 2. Medicines

Supported Information:

- Uses
- Side Effects
- Storage Instructions
- Food Interactions
- General Precautions

Examples:

- Paracetamol
- Dolo 650
- Crocin
- Metformin
- Vitamin D
- Iron Tablets
- Cetirizine
- Omeprazole

Limitations:

- No dosage recommendation
- No prescription generation
- No medication modification
